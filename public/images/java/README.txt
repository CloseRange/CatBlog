Drop Java's photos in this folder and reference them from data/posts.js.

Example:
- /images/java/cardboard-inspection.svg
- /images/java/window-watch.svg
- /images/java/zoomies-hallway.svg

You can use JPG, PNG, WEBP, or SVG files.

Per post, add:
coverImage: { src: "/images/java/example.jpg", alt: "..." }
images: [{ src: "/images/java/example.jpg", alt: "...", caption: "..." }]
